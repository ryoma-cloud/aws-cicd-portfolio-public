# README_要件定義

## 1. 本システムの位置付け

入館証発行管理システムは、実業務向けシステムをそのまま再現することを目的としたものではなく、ポートフォリオとして以下の技術テーマを示すことを目的とする。

- **GitHub、Terraformを用いたIaC化およびCI/CD環境の構築**
- **AIエージェント（ChatGPT Work）を活用したAIネイティブ開発**
- **Docker等のコンテナ技術およびAWSマネージドサービスを活用した、運用負荷・可用性・信頼性を考慮したクラウドネイティブ設計**

機能要件および非機能要件は、原則として上記テーマを実現・評価するために必要な範囲に限定する。  
大規模な業務システムを想定した網羅的な機能追加や、本ポートフォリオの目的への寄与が小さい要件は対象外とする。

## 2. 要件定義方針

実際の業務システムでは開発が必要となる機能・非機能要件であっても、  
ポートフォリオとしての目的やシステム規模および開発範囲、工数を踏まえ、本システムでは意図的に省略する場合がある。

省略・対象外とする事項については単に記載を削除するのではなく、ポートフォリオのため省略・対象外とする旨を明記し、  
実務においては必要となり得る事項を意図的に除外していることを第三者が判別できる状態とする。

また、開発対象としない事項は要件定義工程で確定する。  
要件定義工程にて定義した事項は、原則として後続の設計・実装・テストまで実施するものとし、  
「要件として定義するがポートフォリオのため実装しない」という状態は設けない。

これにより、要件定義書に記載された内容と実際の設計・実装・テストの範囲を一致させ、ポートフォリオとしての対象範囲を明確にする。
