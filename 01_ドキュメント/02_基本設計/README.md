# 基本設計

## 1. 基本設計方針

基本設計は、要件定義書に定めた要件を前提として、システムとして実現すべき主要な構成、処理方式、データ、画面および非機能の実現方式を定義する。

以下の方針に基づき作成する。

- システム全体の構成、主要機能および各機能間の関係を明確にする。
- 外部システムとの連携方式および責任分界を定義する。
- 非同期処理、バッチ処理、状態管理、再処理および冪等性等の主要な処理方式を定義する。
- 主要なデータ構造および外部連携データとの関係を定義する。
- 画面の主要機能、表示内容および操作を定義する。
- 可用性、セキュリティ、監視、バックアップ、復旧、デプロイおよびコストに関する基本方式を定義する。
- AWSサービスの個別パラメータ、IAMポリシー、監視しきい値等の具体的な設定値は、原則として詳細設計で定義する。

基本設計では、要件と設計の対応関係、および主要な設計判断を説明できることを重視する。
