# アプリ詳細設計

## 1. アプリ詳細設計方針

アプリ詳細設計は、基本設計で定めた処理方式・データ・画面を前提として、Lambda、DB・ファイル、Webアプリの具体的な仕様を定義する。

以下の方針に基づき作成する。

- 各処理の入力・出力、入力検証、処理順序、分岐および正常・異常の判定条件を明確にする。
- DBの項目・型・制約、SQL、トランザクションおよび状態更新の条件を定義する。
- CSVの項目・形式・ファイル名と、DB・S3・外部連携の処理順序を定義する。
- 重複実行時の冪等性、再試行、部分失敗および再処理時の整合性を明確にする。
- Webの検索・ページ移動・表示項目・エラー応答を定義する。
- ログに記録する情報と、社員情報・認証情報等の記録しない情報を明確にする。
- AWSリソースの設定値・IAM権限は基盤詳細設計、構築・保守ツールの処理は構築保守の文書で定義する。

実装者が処理を具体化でき、テスト担当者が正常系・異常系の期待結果を判断できることを重視する。
