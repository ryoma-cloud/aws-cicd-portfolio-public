# テスト項目表

項目IDは試験条件と期待結果を追跡するための識別子である。

現行CIはPython構文、ワークフロー模擬実行、Terraform fmt/validateを検証する。環境の構築変更・削除は02_環境操作、状態確認は03_Terraform状態確認、業務・復旧・自動増減・監視設定等の独立試験は`04_テスト`で行う。既存項目の網羅範囲を削らず、実行入口と実証範囲を区別する。要件検証は環境を自動作成・削除しない。監視設定照合を全アラーム発報・配送・実メール受信の成功と扱わない。入力と実行範囲は[ワークフロー利用ガイド](../05_運用/03_ワークフロー利用ガイド.md)に従う。

要件・基本設計・詳細設計を確認するための項目を、機能と確認観点ごとに定義する。各表のIDは結果・証跡との対応に使用する。パラメータ違いを含むID範囲は複数ケースを表し、IDの最大番号は実行件数を表さない。

試験方法と共通の合否基準は[テスト仕様書](テスト仕様書.md)に定義する。

## 項目の読み方

同じ処理でも、入力値・障害箇所・処理段階が異なるケースは別項目とする。「条件・入力値」列で差を示し、期待結果が共通でも各条件を個別に確認する。

| 似ている項目 | 確認する範囲の違い |
| --- | --- |
| T005～T011／T045～T048／T040～T042 | 入力検証関数／API受付とSQS未登録／DBへ直接書き込んだ場合の制約をそれぞれ確認 |
| T058～T061／RS02／A03～A04 | 依存先を模擬したDB・S3の呼出順序／実PostgreSQLで確定済みデータの保持／AWS実環境で再試行・隔離・手動復旧を確認 |
| T063～T069／FLOW02 | S3移動処理の配置別・異常別の分岐／CSV生成から実SFTP送信・DB・S3までの一連の連携を確認 |
| T089～T091／T112～T113 | スモーク試験用／受入試験用の別のHTML判定関数を確認。画面そのものの表示試験はT086～T088 |
