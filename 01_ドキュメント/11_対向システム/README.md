# 対向システム

## 1. 対向システム設計方針

入館証発行管理システムと連携するID管理システム・カード発行業者の構成、動作および接続仕様を定義する。ポートフォリオでは、連携確認に必要な機能をモックとして構築する。

以下の方針に基づき作成する。

- 社員情報を送信するID管理システムと、入館証発行依頼ファイルを受領するカード発行業者の役割を明確にする。
- API・SFTPの接続先、データ、認証、権限および異常時の動作を定義する。
- 構成・設定値・確認条件を対向システムごとの文書にまとめ、本システム側の設計との責任分界を明確にする。
- モックは連携確認に必要な機能に限定し、社員マスタ、カード発行業務、結果通知APIは実装しない。
- 単一環境の一時リソースとして管理し、再構築時は必要なテストデータを再投入する。
