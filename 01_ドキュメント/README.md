# ドキュメント

本ディレクトリでは、要件定義・基本設計・詳細設計・テスト・運用を管理する。ポートフォリオとして説明に必要な文書に絞り、要件・設計・実装・AWS上の稼働状態・テスト結果を区別して記録する。

## 1. 構成

- `00_共通/`：ドキュメント一覧、文書の対象範囲、生成AIの利用
- `01_要件定義/`：対象範囲、機能・非機能要件、対象外
- `02_基本設計/`：全体構成、外部連携、処理、画面、データ、基盤・非機能、運用監視
- `03_詳細設計/`：AWSサービス、アプリ処理、設定値、ログ、監視、セキュリティ、CI/CD
- `04_テスト/`：テスト方針、確認項目と期待結果
- `05_運用/`：監視、障害対応、再送、バックアップ・復旧、停止・再開
- `11_対向システム/`：ID管理システムおよびカード発行業者のモック設計・仕様

基本設計では主要方式・責任分担を定義し、具体的な設定値は詳細設計、運用上の条件と操作は運用設計・手順書で管理する。

主要ドキュメントは[00_共通/01_ドキュメント一覧.md](00_共通/01_ドキュメント一覧.md)から参照できる。
